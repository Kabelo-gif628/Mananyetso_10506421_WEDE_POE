# K&T Electricians Website

## 1. Project Overview

K&T Electricians is a website developed for an electrical services company.
The purpose of the website is to provide users with information about the
company, the electrical services offered, and ways to contact the company
or submit an enquiry.

The website was developed using HTML5 and CSS3.

## 2. Website Pages

The website contains the following pages:

- Home
- About Us
- Services
- Enquire
- Contact Us

## 4. Responsive Design

The website was designed to work on different devices.

The website supports:

- Laptop computers
- Tablets
- Smartphones

CSS media queries were used to adjust the layout, navigation, logo,
text, forms and content for smaller screens.

The website uses responsive styling for screen widths of:

- 900px and below
- 600px and below
- 400px and below

This allows the website content to fit better on different screen sizes.

## 5. Navigation Improvements

The navigation menu was improved based on the feedback from Part 1.

The navigation menu contains links to:

- Home
- About Us
- Services
- Enquire
- Contact Us

Icons were added to make the links easier to identify.

The active page is displayed in green while the other links use the
website's yellow colour.

The navigation and logo were also made fixed so that they remain visible
when the user scrolls down the page.
