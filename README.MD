K&T Electricians Website
1. Project Overview
K&T Electricians is a website developed for an electrical services company.
The purpose of the website is to provide users with information about the
company, the electrical services offered, and ways to contact the company
or submit an enquiry.

The website was developed using HTML5, CSS3 and JavaScript.

Part 3 focuses on improving the functionality and user experience of the
existing website by introducing JavaScript features and considering Search
Engine Optimisation (SEO).

4. Responsive Design
The website was designed to work on different devices.

The website supports:
- Laptop computers
- Tablets
- Smartphones
CSS media queries were used to adjust the layout, navigation, logo,
text, forms and content for smaller screens.

The website uses responsive styling for screen widths of:
- 900px and below
- 600px and below
- 400px and below
This allows the website content to fit better on different screen sizes.

8. Part 3 JavaScript Functionality
JavaScript is used to add interactive features to the existing website.
The functionality is added to the website pages through an external
JavaScript file.

The planned and implemented features include the following, where present
in the final project:
Welcome Message
A welcome message introduces visitors to K&T Electricians.
Live Date and Time
A date and time display can show the current date and time to visitors.
Service Search
The service search allows users to enter a keyword and find matching
electrical services.
Enquiry Form Validation
JavaScript checks that the required enquiry form fields have been completed.
It can display a message to users when the form is completed successfully
or when information is missing.
Interactive FAQ Section
The Frequently Asked Questions section allows users to click a question
to show or hide its answer.
Google Maps
A Google Map can be displayed on the Contact Us page to help visitors
identify the company's location.
Animations and Transitions
Animations and transitions provide visual feedback when users interact
with suitable website elements, such as buttons, images and links.
Image Gallery and Lightbox
The image gallery allows users to select an image and view a larger version.
The lightbox can be closed using its close control or the Escape key.
9. Search Engine Optimisation (SEO)
9.1 Definition of SEO
Search Engine Optimisation (SEO) is the process of improving a website
so that it can be found more easily through search engines.
9.2 Purpose of SEO
The purpose of SEO is to improve a website's visibility in search engine
results and help users find relevant information, products and services.

For K&T Electricians, SEO can help potential customers find information
about the company's electrical services and contact details.
9.3 SEO and User Experience
SEO practices can also support a better user experience. Clear page
titles and headings help users understand the content, while descriptive
links and useful navigation make it easier to move around the website.

A responsive layout helps visitors access the website on different
devices. Descriptive alternative text can also make images more
understandable and accessible.
9.4 Benefits of SEO
The benefits of SEO include:
- Improved website visibility in search results.
- More opportunities to attract relevant visitors.
- Better organisation of website content.
- Improved navigation and accessibility.
- Increased awareness of the company and its services.
- A better experience for website visitors.
9.5 SEO Techniques
SEO techniques that can be used on the K&T Electricians website include:
- Writing descriptive page titles.
- Providing relevant meta descriptions.
- Using relevant keywords naturally in page content.
- Organising content with clear heading elements.
- Adding descriptive alternative text to images.
- Using meaningful links between website pages.
- Making the website responsive on different screen sizes.
- Providing useful and relevant information about the company's services.
Only techniques that have actually been added to the final website should
be described as completed.
